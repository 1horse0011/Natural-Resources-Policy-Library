# B 体系法律法规

林草法律法规按**法律效力层级**组织：

| 目录 | 效力层级 |
|------|----------|
| 01-法律 | 全国人大及其常委会制定的法律 |
| 02-行政法规 | 国务院制定的行政法规 |
| 03-部门规章 | 国家林草局等部门制定的规章 |
| 04-司法解释 | 最高法、最高检发布的司法解释 |
| 05-政策性文件 | 中央、国务院、国家林草局发布的政策性文件 |
| 06-名录 | 各类保护名录、目录 |
| 07-相关法律摘录 | 林草相关法律及涉林草部分摘录 |

清单来源：《林业法律法规等文件汇编（2026版）》206 条。全文从全国人大国家法律法规数据库（flk.npc.gov.cn）、国务院政策文件库、国家林草局官网等官方渠道下载。
