# 林业和草原标准体系（B 体系）

与 A 体系（自然资源标准体系）并列的第二大体系，覆盖森林资源、国家公园、自然保护地、野生动植物保护、草原、湿地、荒漠化防治、森林草原防火、林政管理与执法、生态修复与国土绿化、林草产业、林草基础通用 12 个领域。

分类表见库根目录 [分类表.md](../分类表.md)。

## 目录

- [标准规范](./标准规范/)：B 体系 12 个领域的技术标准（SL2-00 等）。
- [法律法规](./法律法规/)：B 体系法律法规，按效力层级组织（法律 / 行政法规 / 部门规章 / 司法解释 / 政策性文件 / 名录 / 相关法律摘录）。

## 交叉归属

原仓库已收录的 15 个林草相关文件（森林法、草原法、湿地保护法等 3 部法律及 11 项标准、1 份通知）目前仍保留在 A 体系原位置，本库目录与分类表中以交叉标签标出，不重复归档。新补入的林草文件直接进入 B 体系。

## 清单来源

- 法规： 《林业法律法规等文件汇编（2026版）》206 条（历山保护区公众号，2026-06-29）。
- 标准： 国家林草局科技司《林业和草原领域新型地方标准体系汇编（2022版）》及 31 个林草领域标准体系。
