# B 体系标准规范

林业和草原标准体系 12 个领域：

| 代码 | 领域 |
|------|------|
| SL2-00 | 森林资源 |
| GJ2-00 | 国家公园 |
| BH2-00 | 自然保护地 |
| YS2-00 | 野生动植物保护 |
| CY2-00 | 草原 |
| SD2-00 | 湿地 |
| HM2-00 | 荒漠化防治 |
| FH2-00 | 森林草原防火 |
| LZ2-00 | 林政管理与执法 |
| XF2-00 | 生态修复与国土绿化 |
| LC2-00 | 林草产业 |
| JC2-00 | 林草基础通用 |

各领域下按二级分类设子目录（见各领域 README）。分类表见库根目录 [分类表.md](../../分类表.md)。

标准全文查询入口：全国标准信息公共服务平台（std.samr.gov.cn）、国家标准全文公开系统（openstd.samr.gov.cn）、地方标准统一入口（dbba.sacinfo.org.cn，31 省市）。
